# IGFollow AI: Follow the Followers or Followings of a Chosen Account, With Limits and Delays

IGFollow AI is a free Chrome extension for Instagram on desktop. You choose an account, and it follows that account's followers or followings for you, with follow limits and delays that you set. An optional gender-based filter narrows who gets followed.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/gjledilecenicgdidfemjoeecgagokpe?utm_source=github&utm_medium=readme&utm_campaign=igfollow_ai)** | **[Full guide and FAQ](https://www.addonschrome.com/extensions/igfollow-ai-auto-follow.html?utm_source=github&utm_medium=readme&utm_campaign=igfollow_ai)** | **[Video demo](https://www.youtube.com/watch?v=s82yozyeoA0)**

This repository is the public home for IGFollow AI documentation, release notes and the issue tracker. The extension itself is distributed through the Chrome Web Store.

## Features

- Follows the followers or the followings of an account you choose
- Customizable follow limits and delays
- Optional gender-based targeting filter
- Spam-prevention setting that spaces actions out
- Data is processed locally in your browser

## How to use it

1. Install IGFollow AI from the [Chrome Web Store](https://chromewebstore.google.com/detail/gjledilecenicgdidfemjoeecgagokpe?utm_source=github&utm_medium=readme&utm_campaign=igfollow_ai).
2. Open Instagram in Chrome while logged in and choose the target account whose followers or followings you want to follow.
3. Turn on the optional filters you want, and set the follow limit and delay.
4. Press Start Following.

The [full guide](https://www.addonschrome.com/extensions/igfollow-ai-auto-follow.html?utm_source=github&utm_medium=readme&utm_campaign=igfollow_ai) explains each setting.

## Read this before you use it

Instagram restricts automated following. Accounts that follow too many people too quickly can be temporarily blocked or restricted, and no setting can rule that out. Keep the limits low and the delays long, do not run it all day, and stop if Instagram shows a warning. Following people only to be followed back rarely builds an engaged audience, so use it sparingly.
